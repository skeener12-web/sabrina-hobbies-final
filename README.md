# Sabrina's Hobbies — Final Website

Five HTML pages: `index.html`, `about.html`, `creative.html`, `entertainment.html`, `cooking.html`.

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload **the files inside this ZIP** to the repository root (not the ZIP itself and not a containing folder).
3. **Add your existing `logo.jpg`** to the root of the repository. This package does not replace your handmade logo. Until you add it, the navigation shows a text fallback.
4. Open `script.js` and replace `const recipient = '';` with your email address if you want the contact form to prepare an email to you. The email address will be publicly visible in the site's source. The form uses `mailto:`; it does not automatically send or store submissions.
5. In repository Settings > Pages, choose Deploy from a branch, `main`, `/ (root)` and Save.
6. Visit the published website and test all navigation, links and form.

## Rubric checklist
- Home plus four distinct content pages
- Shared external CSS; consistent layout and navigation
- Six hobby images, plus portrait; add existing logo.jpg
- External links to Ravelry, Artists Network, Goodreads, Allrecipes
- HTML unordered lists, comparison table, form with JavaScript
- SEO: unique descriptive titles, meta descriptions, semantic headings/landmarks, meaningful alt text, descriptive link text, responsive viewport
- Mobile-friendly responsive CSS
